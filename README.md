# React 스포츠 전문 병원 관리자 시스템 구축 요청

나는 React + Vite + JavaScript를 학습 중인 초보자다.

참고 사이트:
https://seoulbonbridge.com/

위 사이트의 공개된 화면, 메뉴 구조, 콘텐츠 구성, 예약/상담/게시판/의료진/진료일정 등 사용자에게 제공되는 기능을 분석하고, 이를 기반으로 **스포츠 전문 병원 관리자(Admin) 시스템**을 React로 구현해줘.

중요:

* 실제 사이트의 관리자 페이지에 접근하거나 존재하지 않는 관리자 기능을 사실인 것처럼 가정하지 말 것.
* 공개된 사이트에서 확인 가능한 기능을 기반으로 관리자 기능을 역설계할 것.
* 실제 병원의 개인정보, 환자정보, 의료기록을 가져오거나 저장하지 말 것.
* 모든 환자 데이터와 예약 데이터는 실습용 Mock Data로만 구성할 것.
* 실제 운영 DB/API 없이도 실행할 수 있는 프론트엔드 관리자 시스템을 우선 구현할 것.
* 실제 사이트의 로고, 이미지, 텍스트를 무단 복제하는 방식이 아니라 기능과 정보구조를 참고하여 독립적인 관리자 UI를 만들 것.

# 24. React 개발 규칙

반드시 다음 규칙을 지켜줘.

1. React 함수형 컴포넌트를 사용한다.
2. 가능한 한 작은 컴포넌트로 분리한다.
3. 하나의 파일에 지나치게 많은 기능을 넣지 않는다.
4. 반복되는 UI는 map()을 사용한다.
5. Mock Data는 data 폴더에서 관리한다.
6. 페이지와 재사용 컴포넌트를 분리한다.
7. CSS도 기능별로 유지보수하기 쉬운 구조를 사용한다.
8. 불필요한 라이브러리를 설치하지 않는다.
9. 기존 Vite 기본 예제 코드는 제거한다.
10. npm run dev로 즉시 실행 가능해야 한다.
11. 오류가 발생하면 오류를 숨기지 말고 수정 가능한 구조로 유지한다.

# 25. 상태관리

처음에는 Redux 같은 복잡한 상태관리 라이브러리를 사용하지 말아줘.

React의:

* useState
* useEffect
* props
* Context API

정도로 구현해줘.

실제 백엔드 API가 없는 경우 Mock Data를 사용하고,
데이터 변경이 가능한 것처럼 보이도록 UI를 구현해줘.

가능하면 localStorage를 사용해서 새로고침해도 일부 테스트 데이터가 유지되도록 만들어줘.

# 26. 디자인

전체 디자인은 일반적인 의료기관 관리자 페이지를 참고해서 만들어줘.

원칙:

* 깔끔한 의료기관 스타일
* 흰색 배경
* 남색/파란색 계열의 포인트
* 카드 기반 Dashboard
* 명확한 Sidebar
* 표(Table) 중심의 데이터 관리 화면
* 상태별 Badge
* 버튼의 기능이 직관적이어야 함
* 여백을 충분히 사용
* 초보자가 화면을 보고 기능을 쉽게 이해할 수 있어야 함

환자용 홈페이지가 아니라 **병원 직원이 사용하는 관리자 페이지**라는 느낌으로 디자인해줘.

# 30. 초보자 교육용 주석

내가 React를 배우는 초보자이므로 핵심 코드에는 주석을 달아줘.

예:

// 예약 데이터를 화면에 표시하기 위한 상태
const [reservations, setReservations] = useState([]);

단, 모든 코드에 주석을 무조건 달지는 말고,
처음 배우는 사람이 이해하는 데 도움이 되는 핵심 부분에만 주석을 달아줘.

# 33. 최종 실행 조건

최종 결과는 다음 명령으로 실행되어야 한다.

npm install

npm run dev

그리고 브라우저에서:

http://localhost:5173

으로 접속했을 때 관리자 로그인 화면이 보여야 한다.

로그인 후 Dashboard가 정상적으로 표시되어야 한다.

모든 Sidebar 메뉴를 클릭했을 때 실제 React 페이지가 연결되어 있어야 하며,
빈 화면이나 "준비 중"만 표시하는 페이지를 만들지 말아줘.

각 페이지에는 실제로 동작하는:

* 검색
* 필터
* 추가
* 수정
* 삭제
* 상태 변경
* 상세보기
* 페이지네이션

중 해당 기능을 적절히 구현해줘.

# 34. 최종 점검

완성 후 스스로 다음을 확인해줘.

□ npm run dev 정상 실행

□ 로그인 정상 동작

□ Dashboard 정상 표시

□ Sidebar 모든 메뉴 연결

□ 각 페이지 렌더링 오류 없음

□ React Console 오류 없음

□ Mock Data 정상 출력

□ CRUD UI 정상 동작

□ 모달 정상 동작

□ 검색 정상 동작

□ 필터 정상 동작

□ 반응형 정상 동작

□ 새로고침 후 React Router 오류 없음

□ import 경로 오류 없음

□ 사용하지 않는 import 제거

□ 기본 Vite 로고 및 카운터 제거

문제가 있다면 문제의 원인을 설명한 후 최소한의 수정으로 해결해줘.

완성된 프로젝트의 폴더 구조를 마지막에 다시 한 번 보여줘.
